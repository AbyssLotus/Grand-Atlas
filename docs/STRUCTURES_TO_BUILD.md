# Structures to build

A short list of hand-built structures for Grand Atlas (drafted 2026-11-10). The mod has none of its
own yet: the set pieces and landforms are places with nobody in them. Each one below gives a place we
already have a reason to visit, a landmark to see from far off, or a way to find the next thing.

## How to hand them over

- Build in a flat creative world and save each with a **structure block** (corner mode, up to 48x48x48;
  bigger builds as several pieces that share a wall).
- Leave **structure void** wherever the terrain should show through (under overhangs, round the base).
- Put a **jigsaw block or a marker** (any named sign is fine) where chests, spawners or the entrance
  go; I'll wire loot tables and placement.
- Note which side is the **front** and what the build must sit on (flat ground, a cliff face, water).
- Vanilla blocks plus Grand Atlas's own (aurora crystal, selenite, amber sap, glowcap, glowworm silk).
- I'll write the placement rules: where each may appear, how rare, and terrain fitting.

## The list

Sizes are footprint x height, and are targets, not limits. "Variants" is how many versions keep it
from looking stamped.

## Suggested order

1. **Waystone cairn** and **Well-keeper's ring**: small, and both help players find what exists.
2. **Aurora observatory**, **Bone-hunters' camp**, **Root-warden's rooms**: they fill the set pieces you
   have already been reviewing.
3. The surface landmarks (8-11), one per landform, as each landform gets its review.
4. **Hollow hermitage** and **Black-shore pier** last: they need the most care to place.

## Notes

- Structures may run into set pieces (your rule, 2026-11-10); only the hanging lake, well shaft,
  rising fall, the Worldroot's trunk and the Titan's skull are kept clear. These builds are placed on
  purpose, so they don't go through that filter.
- Number 5 needs no terrain fitting at all (the rooms exist), so it is the quickest to wire in.
- If you'd rather not build some of these, say which and I can generate them in code in the same
  style as the set pieces. Hand-built will look better for anything with an interior.
